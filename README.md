# Daily Consumption Auditor
Free Android web app that totals drug consumption from photos of the handwritten IRC Daily Consumption register.

1. Get a free Gemini API key: https://aistudio.google.com → Get API key (no card needed).
2. Open the app (GitHub Pages link) in Chrome → ⚙️ → paste key → Load models.
3. Pick the date, add left + right photos of each page, mask the names column on left halves, Start audit.
4. Check "Review flags", then export CSV / copy / print.

Developer notes: see CLAUDE.md. Test without internet: use API key `MOCK`.
